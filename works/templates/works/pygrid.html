Управление роботом — основы Python

      
    

    

    


      
1. Что такое программа

      
Программа — это последовательность команд, которые компьютер выполняет по порядку сверху вниз. Каждая строка кода — одна инструкция.

      
from robot import *   # подключаем библиотеку робота
move()                # команда: двигаться вперёд
turn_left()           # команда: повернуть налево
move()                # снова вперёд

      
Порядок важен: если поменять строки местами, робот пойдёт другим путём.


      
2. Команды движения

      
Робот понимает четыре команды для перемещения:

      
move()        # шаг вперёд (в текущем направлении)
turn_left()   # поворот на 90° влево (против часовой)
turn_right()  # поворот на 90° вправо (по часовой)
pick()        # подобрать предмет на текущей клетке

      
Важно: move() всегда идёт вперёд — туда куда смотрит робот. Чтобы идти в другую сторону, сначала нужно повернуться.

      
Если перед роботом стена и вызвать move() — программа остановится с ошибкой.


      
3. Проверка окружения

      
Робот может «видеть» что находится вокруг:

      
sense()         # что впереди: 'wall', 'item', 'goal', 'empty'
sense_right()   # что справа
sense_left()    # что слева
sense_here()    # что на текущей клетке: 'item' или 'empty'
is_at_goal()    # True если робот стоит на цели


      
4. Циклы — повторение действий

      
Чтобы не писать одну команду много раз, используют цикл for:

      
# Вместо пяти строк move():
for i in range(5):
    move()         # выполнится 5 раз

      
Цикл while повторяет пока условие истинно:

      
while sense() != 'wall':
    move()   # идём вперёд пока нет стены


      
5. Условия — ветвление

      
Оператор if позволяет роботу принимать решения:

      
if sense() == 'wall':
    turn_right()   # если стена — повернуть
else:
    move()         # иначе — идти вперёд

      
Комбинация цикла и условия — основа «умного» робота:

      
for _ in range(100):
    if sense() == 'wall':
        turn_right()
    else:
        move()
    if is_at_goal():
        break   # остановиться когда достигли цели


      
6. Функции — повторяемые блоки

      
Если один и тот же код нужен в нескольких местах, его выносят в функцию:

      
def go_right(n):
    """Идти вправо n шагов"""
    for i in range(n):
        move()

def turn_around():
    """Развернуться на 180°"""
    turn_right()
    turn_right()

# Использование:
go_right(3)
turn_around()
go_right(3)

      
Функция определяется один раз через def, а вызывается сколько угодно раз.


      
7. Текущая позиция

      
Робот знает где он находится:

      
get_x()          # X-координата (0 = левый край)
get_y()          # Y-координата (0 = верхний край)
get_direction()  # направление: 'N', 'E', 'S', 'W'

      
Это помогает строить маршруты: например, «иди пока X < 5».
