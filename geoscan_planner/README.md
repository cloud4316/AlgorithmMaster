# Geoscan UAV Flight Planner

Веб-сервис автоматического планирования полётных миссий для группы БПЛА Geoscan с двухкритериальной оптимизацией маршрутов.

## Возможности

- **Полётные маршруты**: автоматическая прокладка «косилочного» (boustrophedon) маршрута съёмки
- **Двойная оптимизация**: «минимум времени» vs «минимум износа» — сравнение на одном экране
- **Разделение зон**: пропорциональное разбиение полигона между несколькими БПЛА
- **Высотное разделение**: каждый БПЛА получает H_базовая + i×10 м для исключения конфликтов
- **Съёмочная нагрузка**: RGB, мультиспектр, ИК, LiDAR, геофизика — автоматический расчёт GSD, полосы, интервала
- **Зоны**: бесполётные зоны (исключение из маршрута), граница ВП, ВПП, резервные площадки
- **Импорт/экспорт**: GeoJSON, KML (Google Earth), сохранение/загрузка сценариев
- **Парк БПЛА**: Geoscan 201 (самолёт), Geoscan Gemini, Geoscan 801 (мультироторы)

## Быстрый запуск

### Требования

```
Python 3.10+
pip install fastapi uvicorn shapely simplekml
```

### Запуск сервера

```bash
cd geoscan_planner/backend
python main.py
```

Сервис доступен по адресу: **http://localhost:8001**

### Тестирование с демо-сценарием

1. Откройте http://localhost:8001
2. Нажмите **⬇ Пример** — скачается `demo.geojson` с Щёлковским районом Подмосковья
3. Нажмите **📂 Импорт GeoJSON** и загрузите этот файл
4. Нажмите **🚀 Рассчитать маршруты**

## Структура проекта

```
geoscan_planner/
├── backend/
│   ├── main.py          # FastAPI: endpoints, models, response assembly
│   ├── optimizer.py     # Multi-UAV task allocation (min_time / min_wear)
│   ├── coverage.py      # Boustrophedon strip generation
│   ├── export.py        # KML / GeoJSON export
│   └── uav_specs.py     # UAV fleet & payload specs
└── frontend/
    ├── index.html       # Single-page application
    ├── app.js           # Leaflet map + sidebar logic
    ├── style.css        # Dark theme UI
    └── demo.geojson     # Sample input: Щёлковский район
```

## Алгоритм оптимизации

| Критерий | Алгоритм разбиения | Назначение |
|---|---|---|
| **min_time** | Пропорционально ёмкости (скорость × ресурс) | Равномерное заполнение времени на батарею |
| **min_wear** | Пропорционально скорости + назначение ближайшего | Минимальный суммарный налёт |

Угол полос = (направление ветра + 90°) % 180° — полёт поперёк ветра.
